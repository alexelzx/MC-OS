## Overview
MC-OS is a standalone, retro-style Windows desktop application engineered specifically for Minecraft Server Government Roleplay and Citizen Management. 

## Key Features
* **Fully Offline Operation:** Functions entirely on your local hardware. No internet connection is required, and it does not communicate with external servers.
* **Local Data Management:** All government data, citizen records, and treasury functions are stored safely on your machine.
* **Administrative Modules:** Includes interfaces for Customs, Citizens, Banking, Water, Tax & Bills, and Police & NSD.
* **Manual Data Backup:** Export and import government data securely via local JSON files.

## Critical Data Warning
This application features **no cloud backups, remote synchronization, or external recovery systems**. If the application or its local files are deleted, all data is permanently destroyed. Users are strictly responsible for maintaining their own manual JSON backups.

## Installation
1. Navigate to the **Releases** section of this repository.
2. Download the latest `MC-OS Setup.exe` installer.
3. Execute the installer and follow the on-screen setup wizard.
